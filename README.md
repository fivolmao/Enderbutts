# 🍑 Enderbutts

### Ride your enderpearls. Literally.

**Enderbutts** is a Quark V6 plugin that changes the way enderpearls work. Instead of simply throwing an enderpearl and teleporting, players get to ride on top of their thrown pearl as it travels through the air!

Why throw an enderpearl when you can ride it?

[![Buy Me A Coffee](https://img.shields.io/badge/Buy%20Me%20A%20Coffee-Support%20Enderbutts-FFDD00?style=for-the-badge&logo=buy-me-a-coffee&logoColor=black)](https://www.buymeacoffee.com/fivo)

## ✨ Features

- 🏇 **Enderpearl Riding** – Throw an enderpearl and automatically ride on top of it.
- 🚀 **Midair Adventures** – Travel alongside your enderpearl as it flies through the air.
- 🌌 **A New Way to Teleport** – Experience enderpearls like never before.
- 🔌 **Quark V6 Integration** – Built specifically for Quark V6.

## 🎮 How It Works

1. Grab an enderpearl.
2. Throw it like you normally would.
3. Your player mounts the enderpearl.
4. Enjoy the ride!
5. Arrive at your destination.

**Enderpearl throwing will never be the same again.**

## 📥 Installation

1. Download the latest `Enderbutts.phar` from the [Releases](../../releases) page.
2. Place the PHAR file into your Quark V6 `plugins` directory.
3. Restart your server.
4. Grab some enderpearls and start riding!

## 🛠️ Building From Source

### Requirements

- PHP
- PHAR extension
- Quark V6 development environment

### Build Instructions

Clone the repository:

```bash
git clone https://github.com/fivolmao/Enderbutts.git
cd Enderbutts
```
Build the PHAR:
```bash
php -d phar.readonly=0 tests/build-plugin-phar.php
```
The generated `Enderbutts.phar` will be ready to install on your Quark V6 server.
